Change the job:

The essay becomes one item in a managed collection.The shell is legible and the action is visible. Its navigation rail, statistics and equal containers make collection structure more prominent than the essay's voice; changing the accent would not change that hierarchy.

Change the job:
work an archive.

A field researcher finding a place, species record or saved collection repeatedly needs stable navigation, filters and regular entries. B's shell can serve that utility directory. The expressive composition suits the essay's entrance; it need not govern the archive's working view.

Transfer: character comes from how the subject controls scale, crop, pacing and type. It does not require ornamental clutter or unusual controls.

04 · Give geometry an owner

A control family is a relationship,
not a collection of local fixes.

Brief. A product-image editor places save status, output shape, preview and export in one toolbar. The export label can change; status is information, not an action.

A   A shared control family, undermined by local choices

Stoneware / market launchImage editor
Saved locally

A stale width reservation.save-slot { width: 160px }
The passive status is short, but its wrapper still reserves room for a former, longer message.

A wrapper changes the control.preview-slot { min-height: 40px }
Flex stretch makes Preview 40px high, despite the shared control's 36px minimum.

A valid variant in the wrong group.control--compact { --control-size: 32px }
Output shape uses the compact variant next to default-sized actions, without a density reason.

B   Keep the family; remove the competing geometry

Stoneware / market launchImage editor
Saved locally

Toolbar owns placement

Flex layout, grouping, gaps and alignment live on the toolbar. Its containers do not supply control padding or stretch a button beyond its family size.

The control owns its defaults

.control declares its own size, padding, type, border and radius. It works outside this toolbar too. This group's actions use the same default density.

Content owns useful width

“Preview” stays compact; “Export image” gets the width of its label and icon. Passive status remains unboxed and quieter, without an unused width reservation.

Stoneware / market launch700px available · longer label · save pending
Saving locally…

Changed content, same ownership.
The same flex layout wraps the action group when both regions no longer fit. Export grows for its label, retaining the family metrics. Here export needs a saved version: the pending save changes status and availability, not control size.

When a difference
has a real job.

A changing zoom readout may reserve width to keep adjacent controls still. A compact variant can serve a dense table, while a touch action needs a larger target. Those differences follow content or input conditions. Here the passive status and action buttons legitimately differ; unrelated wrapper dimensions do not justify three action heights.

Transfer: align the relationship that matters. Equal heights can unify related actions; unequal widths, a quieter status or a larger touch target can be correct.
