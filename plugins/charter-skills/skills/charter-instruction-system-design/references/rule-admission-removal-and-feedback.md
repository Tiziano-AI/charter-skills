# Choosing and revising instructional knowledge

Recurring instructions spend attention on every turn they are present. Their
value lies in a consequential distinction the model would otherwise miss, not
in being true or sounding responsible. Assess a candidate by the situation it
addresses, the action it is expected to change and the consequence of that
change. A reversible candidate can be adopted and judged in real work.

## Different defects call for different changes

**Retain** when knowledge is useful, properly owned and intelligible. Existing
substance does not become obsolete because the package around it is being
redesigned.

**Rewrite or enrich** when the job survives but the model lacks a useful
distinction, causal explanation, example or domain fact. A concise directive
may need more knowledge, not a stronger imperative.

**Move or merge** when the useful meaning belongs to a narrower owner or is
split across competing carriers. One source can have required projections;
duplication across independent editable owners creates drift.

**Retire** when another survivor supplies the meaning, the underlying mechanic
has disappeared, or observed use shows the instruction has no useful effect or
causes harm. A greenfield design can change all wording and structure while
keeping the actual obligations.

Checks and questions scale, so over-applying them harms as much as omitting
them. An authority, fidelity or truth boundary is not a scalable preference,
and weakening it to balance the text changes the contract.

## A field miss is diagnostic evidence

The useful contrast keeps the intended result, what actually happened, the
input composition capable of causing it and the material consequence. Check
whether knowledge was wrong, absent, unused or insufficient for the work.
These observations may still leave multiple explanations: a correct account
of good form does not show that the agent can construct or recognize it.

Suppose an agent produces meticulous verification notes but not the requested
artifact. Adding another completion reminder may keep the same proxy: checks
as the work. The better intervention supplies a model of when verification
informs delivery and when it displaces it, if that distinction was absent or
wrong; if it was already present, repeating it does not address the miss.
Conversely, an agent with the right
model but no access to the output tool has a capability or delivery problem,
not necessarily an instruction problem.

## Checking a change

When a change restrains behavior (asking, refusing, checking), try it on a case
where the rule should not fire as well as one where it should: a case that
contains only the conflict hides overcorrection. When quality matters, judge
the artifact and its receiver rather than compliant phrasing. For a sensitive
scope, a single severe boundary violation can reject a candidate, while one
good occurrence does not establish reliability everywhere.
